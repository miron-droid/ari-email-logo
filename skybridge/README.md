# Skybridge Logistics LLC — email kit

Единый конструктор подписи и bid template: https://miron-droid.github.io/ari-email-logo/skybridge/

Вкладки переключаются на одной странице, контакты общие. #bid открывает предпросмотр ставки.

## Установка подписи

1. Откройте конструктор и заполните имя, контакты и реквизиты. Пустые поля не включаются в подпись.
2. Нажмите «Скопировать для CargoETL».
3. CargoETL: Settings → Dispatcher Settings → Bid email signature → HTML mode → Save settings.
4. Для Gmail нажмите «Скопировать для Gmail» и вставьте в Настройки → Все настройки → Подпись.

«Скачать подпись» сохраняет HTML с текущими данными. Готовый signature.html содержит фирменный баннер и Dispatch Team, без придуманных контактов. Данные конструктора сохраняются локально в браузере. Переключатель «Анимация моста и логотипа» выбирает GIF или статичный полный логотип; при первом открытии с настройкой reduced motion выбран статичный вариант.

## Установка bid template

1. Выберите вкладку Bid template на этой же странице, нажмите «Скопировать bid template».
2. CargoETL: Settings → System Settings → Bid email template → HTML mode → Save settings.
3. Сохраните личную подпись отдельно. CargoETL вставляет её вместо [sign].

Переменные сохранены: `${brokerPrice}`, `{MCNumber}`, `{miles}`, `{dims}`, `{eta}`, `{payload}`, `[sign]`. ETA — время в пути до pickup, не время прибытия по часам. Notes заполняется вручную по конкретному рейсу. Демонстрационные значения предпросмотра не включаются в экспорт. Срок действия ставки не задан.

## Файлы анимации

Широкий фирменный баннер имеет пропорции 21:9: мост собирается, появляется золотая дорога, проезжает машина, затем открывается название SKYBRIDGE. Название включено в изображение, отдельного повторного заголовка под баннером нет. В email-подписи баннер занимает всю ширину; контакты расположены компактными строками ниже.

- `assets/skybridge-reveal.gif` — анимация для HTML-подписи.
- `assets/skybridge-reveal-static.png` — полный статичный логотип.
- `assets/skybridge-reveal.mp4` — версия заставки высокого качества.

Экспорт использует абсолютные HTTPS-адреса изображений на GitHub Pages. Локальный предпросмотр использует файлы assets. Размер изображения в HTML — 630×270 px; ширина уменьшается вместе с письмом. Экспорт состоит из inline-таблиц без зависимости от CSS конструктора.

## Проверка

При обновлении баннера проверяются JS, экранирование введённых данных, HTTPS-адреса GIF и статичного изображения, отсутствие контактов в пустом шаблоне, точность переменных bid template. Полный пользовательский сценарий: редактирование, переключение подпись/bid без перезагрузки, копирование HTML и rich HTML, скачивание, сохранение/сброс, предпросмотр на экране 390 px с длинными контактами.

В рабочие настройки CargoETL комплект не установлен; отправка реального письма не выполнялась.

Сцена сборки моста, проезда грузовика и превращения в знак сгенерирована в Higgsfield / Seedance 2.5 по фирменному логотипу и видеореференсу. Точная надпись добавлена при монтаже в Higgsfield sandbox. GIF: 560×240 px, 127 кадров, 12,7 с, около 2,6 MiB; первый кадр — полный логотип. MP4: 1260×540 px, 24 fps, 12,04 с.
