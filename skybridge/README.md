# Skybridge Logistics LLC — email kit

Единый конструктор подписи и bid template: https://miron-droid.github.io/ari-email-logo/skybridge/

Вкладки переключаются на одной странице, контакты общие. #bid открывает предпросмотр ставки.

## Установка подписи

1. Откройте конструктор и добавьте имя, прямой телефон и рабочий email диспетчера. Контакты компании уже заполнены по предоставленному договору; остальные реквизиты можно изменить. Пустые поля не включаются в подпись.
2. Нажмите «Скопировать подпись».
3. CargoETL: Settings → Dispatcher Settings → Bid email signature → HTML mode → Save settings.
4. Для Gmail нажмите «Скопировать для Gmail» и вставьте в Настройки → Все настройки → Подпись.

«Скачать подпись» сохраняет HTML с текущими данными. Готовый signature.html содержит название, логотип и подтверждённые контакты компании. Данные конструктора сохраняются локально в браузере. Для ранее сохранённых форм пустые телефон офиса, адрес и Tracking / POD заполняются из договора один раз; непустые сохранённые значения не меняются. «Очистить личные данные» очищает имя, прямой телефон и личный email, сохраняя контакты компании и настройки анимации. Переключатель «Анимация моста и логотипа» выбирает GIF или статичный полный логотип; при первом открытии с настройкой reduced motion выбран статичный вариант.

## Контакты из договора

Источник: предоставленный пользователем `Skybridge_Contract_Editorial_Redesign Copy.pdf`, 12 страниц. Текст извлечён из PDF; страницы 1, 8, 9 и 11 проверены визуально.

- Название: Skybridge Logistics LLC — страница 1.
- Адрес: 4050 Skyron Dr, STE A12, Office 1, Doylestown, PA 18902 — страницы 1, 10 и 11.
- Основной телефон: +1 (267) 557-0001 — страницы 9–12; на странице 11 прямо обозначен MAIN LINE NUMBER. Это телефон офиса, не личный Direct.
- Tracking / POD: tracking@skybridgecompany.com — страницы 5, 10–12. Это отдельный адрес для отслеживания и документов; он не подставляется в личный email диспетчера.

Имя диспетчера, личный телефон и email не заданы в общем шаблоне. Поля подписантов на странице 8 договора пустые. MC, USDOT и сайт не указаны в договоре, но позднее подтверждены предоставленным пользователем скриншотом заполненных настроек от 9 октября 2026 года: MC 1791442, USDOT 4521307, skybridgecompany.com. Они включены в корпоративные значения по умолчанию; отдельная одноразовая миграция заполняет только пустые поля ранее сохранённых форм, сохраняя непустые пользовательские значения. После миграции намеренно очищенные поля остаются пустыми. Имя Max Jackson и персональный email со скриншота используются только для проверки заполненного примера, не как значения по умолчанию.

## Установка bid template

1. Выберите вкладку «Шаблон ставки» на этой же странице, нажмите «Скопировать шаблон ставки».
2. CargoETL: Settings → System Settings → Bid email template → HTML mode → Save settings.
3. Сохраните личную подпись отдельно. CargoETL вставляет её вместо [sign].

HTML шаблона ставки экспортируется одной строкой: это сохраняет одинаковое расположение блоков и в HTML-режиме CargoETL, и в режиме, который преобразует переводы строк в `<br>`.

Переменные сохранены: `${brokerPrice}`, `{MCNumber}`, `{miles}`, `{dims}`, `{eta}`, `{payload}`, `[sign]`. ETA — время в пути до pickup, не время прибытия по часам. Notes заполняется вручную по конкретному рейсу. Демонстрационные значения предпросмотра не включаются в экспорт. Срок действия ставки не задан.

## Файлы анимации

Подпись имеет ширину до 640 px и собрана в единый горизонтальный блок. Слева — анимированный логотип и MC/USDOT; справа — название компании, имя, должность и все контакты. Колонки 33/67 разделены тонкой золотой вертикальной линией с небольшими отступами. Полноширинные шапка и нижние линии убраны, чтобы между логотипом и контактами не оставалось широкого пустого пространства. Адрес и сайт продолжают правый контактный блок. Длинные строки переносятся без обрезки; высота подписи определяется содержимым. Изображение отображается максимум 190×166 px и уменьшается вместе с письмом. Шаблон ставки сохраняет ширину до 720 px и существующие переменные.

Художественный стиль заставки — синий металл, серебристые грани и золотая дорога на белом фоне. Дорога и мост собираются, грузовик движется по дороге и уменьшается в перспективе, затем появляется название SKYBRIDGE и крупная строка LOGISTICS LLC. Анимация воспроизводится один раз и остаётся на готовом логотипе. Кнопка «Повторить анимацию» перезапускает только предпросмотр. Редактирование текста и реквизитов сохраняет элемент изображения без перезапуска.

- `assets/skybridge-clear-once.gif` — анимация для HTML-подписи, 480×420 px.
- `assets/skybridge-clear-static.png` — полный статичный логотип, 480×420 px.
- `assets/skybridge-clear.mp4` — версия заставки высокого качества, 960×840 px.

Экспорт использует абсолютные HTTPS-адреса изображений на GitHub Pages. Локальный предпросмотр использует файлы assets. Видеоплеер шириной до 480 px, с ручным запуском и без автоматического повтора. Экспорт состоит из inline-таблиц без зависимости от CSS конструктора.

## Проверка

При обновлении баннера проверяются JS, экранирование введённых данных, HTTPS-адреса GIF и статичного изображения, точность подтверждённых контактов, отсутствие выдуманных личных данных и точность переменных bid template. Полный пользовательский сценарий: заполнение новой формы, однократное заполнение пустых корпоративных полей ранее сохранённой формы, сохранение непустых пользовательских значений, очистка личных данных, редактирование без перезапуска GIF, переключение подпись/bid без перезагрузки, копирование HTML и rich HTML, скачивание и предпросмотр на экране 390 px с длинными контактами.

По предоставленному скриншоту предыдущая версия подписи и bid template уже сохранена в CargoETL. После этого обновления компоновки нужно скопировать и сохранить подпись заново; HTML шаблона ставки не менялся. Реальная отправка письма агентом не выполнялась.

Ключевой кадр художественной заставки создан в Higgsfield / GPT Image 2.5. Сборка фирменного знака и проезд грузовика анимированы в Higgsfield / Seedance 2.5. Точная фирменная типографика добавлена при монтаже в Higgsfield sandbox.

Текущие GIF и статичный логотип имеют пропорции 480×420 px; MP4 — 960×840 px. GIF: 97 кадров, 6,06 с, 1 484 722 байта, без расширения повтора. Заполненный пример Max Jackson без прямого телефона занимает примерно 640×242 px. Старые файлы сохранены для ранее экспортированных подписей. Чтобы применить уплотнённую компоновку и новый логотип, подпись нужно скопировать из конструктора и сохранить заново.
