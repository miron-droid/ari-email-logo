SHIFT LINE TRANSIT — READY SIGNATURE

Готовая версия для Aaron Black по последней присланной подписи.

1. Откройте index.html.
2. Нажмите «Скопировать HTML для CargoETL».
3. В Settings → Bid email signature включите HTML mode.
4. Вставьте весь код вместо прежнего и сохраните настройки.
5. Отправьте тестовое письмо.

В shift-signature.html находится только таблица подписи, без скриптов.
В index.html есть копирование кода и визуальной подписи.
HTML можно редактировать в CargoETL Visual mode: для другого сотрудника замените имя, должность, личный номер и email. В HTML обновите также tel: и оба mailto:.
